Quick Start

1

Run Belatstrap as Administrator

Right-click Belatstrap.exe → Run as administrator. Admin rights are required for memory injection and for the GUID/MAC spoofers to work.

2

Pick your language

Choose one of the 12 supported languages. Your choice is remembered — next launch skips straight to the installer check.

3

Let the installer verify Roblox

Belatstrap checks your Roblox version against the one its offsets were dumped for. If your client is outdated it downloads and installs the matching version automatically. If the download fails, hit Retry Download.

4

Sign in with Discord

Official OAuth — no password involved. One sign-in keeps you verified for 5 hours.

5

Load a config and inject

In the Injector tab: Load Config (or build your own FFlags) → press INJECT with Roblox running. Flags are written directly into Roblox's memory.

6

Apply bundles for quick setups

Use the Bundle tab presets (Desync, No Texture, Skip MIP, TSB, ESP) for one-click tweak combos.

Language & Installer

Language selection

The installer screen lets you pick from 12 languages: English, Spanish, French, German, Portuguese, Russian, Chinese, Japanese, Filipino, Vietnamese, Arabic and Indonesian. The whole UI — installer, main menu, dialogs — switches language. Your pick is saved, so on the next launch the selection screen is skipped and Belatstrap jumps straight to checking your Roblox version.

Version check & Roblox download

Belatstrap works against a specific Roblox build (its offsets are dumped for that version). On every launch it compares your installed Roblox against the latest supported version:

  • Up to date → straight to Continue to Application.
  • Outdated or missing → Belatstrap downloads and installs the latest Roblox automatically, showing progress. If the download is interrupted, use Retry Download.
  • You can always Skip Installer — but the offset database may then not match your Roblox build.

If Roblox is currently running, Belatstrap tells you on screen — close it first so the installer can replace the client files.

Discord Login (5H Session)

Belatstrap uses Discord's official OAuth to verify that you're a real Discord user. The login happens in Belatstrap's own browser window:

  • You approve only the info shown on Discord's authorization screen.
  • Your Discord password is never seen, stored or transmitted to Belatstrap.
  • After a successful login your session stays valid for 5 hours — no repeated sign-ins while you use the app.
  • If the connection to Discord fails you'll see a clear error and can retry.
  • Revoke access any time via Discord → User Settings → Authorized Apps.

Loading Screen

After Discord verification, a short "PREPARING YOUR ENVIRONMENT" loading screen runs for a few seconds while Belatstrap prepares your session, then the main window opens (1000 × 600, centered on your monitor). This is normal — just wait a moment.

Main UI Overview

The main window has a dark sidebar on the left with six tabs: Injector, Settings, Others, Bundle, Performance and Terminal. The top bar shows the Belatstrap logo, a Status line (e.g. "Status: Idle" or "Applying" while flags are being written) and a close (X) button — closing asks for confirmation.

If Roblox launches while the app is open, a small toast appears in the corner: "Roblox is currently running." — useful to know when to restart it after config changes.

Injector Tab

The heart of Belatstrap. It shows the detected Roblox PID, the currently loaded config, and an INJECT button that becomes INJECTED once the flags are written into Roblox's memory process.

Your flags

The YOUR FLAGS panel lists everything in your current config with a live search box ("Found N flags matching …"). Each flag can be:

  • Edit — change the flag value (Flag name + Value, then Save/Cancel).
  • Remove — drop it from the list.
  • Remove All — clears every flag (asks for confirmation, since it removes them from the Roblox memory process).

Clear Log wipes the injector console output below the list.

Empty states you may see

  • "No flags loaded. Load a Config." — go to Settings → Load Config or use the FFlags Manager.
  • "No supported flags found." — your loaded flags have no valid offsets for the current Roblox version. Update your Roblox (installer) and re-dump/re-save the config.
  • "Unsupported flag — read-only" — some flags can't be injected; they're informational only.

Settings Tab

General

  • Language — switch the UI language on the fly (same 12 languages as the installer).
  • UI Keybind — click the box and press any key to bind show/hide of the UI (ESC cancels).
  • Auto Apply — automatically apply your loaded flags when injecting.
  • Streamproof — hide sensitive parts of the UI when you're streaming.
  • Instant — apply flags instantly without delays.
  • Save Config / Load Config — persist or restore your whole flag setup (JSON files).

For some changes to take effect you must restart Roblox — Belatstrap shows a "Restart Roblox" button right in the settings when that's the case.

Miscellaneous

  • MAC Address Spoofer — one click to spoof your network adapter's MAC address ("Spoofing MAC address…" while it works).
  • Target FPS — set the FPS cap you want.
  • Memory Cleaner — free up Belatstrap's memory usage with one click.

Font Changer

Browse Font → pick a .ttf/.otf → Apply & Lock to keep it, Restore Default to go back, or Apply & Restart to apply it with a fresh start.

Cursor Changer

Same idea as the font changer: Browse Image → apply and lock your own cursor, restore the default, or apply and restart.

Presets & Graphics Quality

Presets are one-click FFLAG setups (performance, FPS boost, graphics, stability). Graphics Quality offers LOW / MID / HIGH profiles with an Apply & Restart button.

Others Tab (GUID Spoofer)

The Control section manages your machine's System GUID:

  • Change GUID — generate and apply a new system GUID manually.
  • Auto GUID — keep re-spoofing on a timer so the GUID never stays static.
  • Use Interval + Seconds — when enabled, your FFLAGS are applied in batches every N seconds (12–20s slider) instead of all at once, to avoid stuttering while Roblox is running.
  • Status readouts: Current System GUID, Changes count and Last Change timer.

If you see "✗ Cannot read System GUID" you are not running as Administrator — close Belatstrap and relaunch it as admin.

Bundle Tab

Ready-made bundles that apply a set of flags in one click. Each one shows "⏳ Applying flags…" while working. The tab warns you if Roblox isn't running ("⚠ Roblox not running!") or if you haven't injected yet ("⚠ Inject first!").

  • Desync — toggle desync functionality, with an adjustable interval in milliseconds.
  • NO TEXTURE — remove all textures from the game for a big FPS jump.
  • SKIP MIP — skip mipmapping for better performance.
  • BLADEBALL LAG BALL — BladeBall-specific lag ball settings.
  • TSB — the TSB bundle preset (fast M1, long range, etc.).
  • ESP FFLAGS — enable ESP and debug visualization flags.

Performance Tab

A live Performance Monitor showing your system state, including GPU usage — handy for confirming your FPS/performance tweaks are actually helping.

Terminal Tab

A terminal-style page inside the app. Use it for command-style interaction and diagnostics.

FFlags Manager

Build and manage your flag list from the app's 12,071-offset database:

  • Search — type to filter available flags.
  • [Supported Only] — hide read-only flags that can't be injected.
  • Add FFlag — move flags from "Available FFlags" into "Selected FFlags", then apply.
  • Edit Flag — tweak a flag's value before applying.
  • Remove Selected — clean up your selection.
  • Close Roblox — offers to close Roblox (asks "Close Roblox now?" first) when a full restart is needed.

The offset database is re-dumped after every Roblox update — keep your client updated for full compatibility.

Safety & Troubleshooting

Antivirus false positives

Belatstrap writes flags into Roblox's memory — that's exactly what malware does too, so some antivirus engines flag it. It's a false positive. Add Belatstrap to your antivirus exclusions, and only download from the official source. You can verify the build hash via the note page.

Common issues

  • "Cannot read System GUID" → relaunch as Administrator.
  • Flags not applying → Roblox must be running and you must inject first; restart Roblox after big config changes.
  • "No supported flags found" → your config's flags don't match the current Roblox build; update Roblox via the installer and re-save your config.
  • Session expired → the 5-hour Discord session ran out; sign in again (one click).
  • Download failed → press Retry Download in the installer.
